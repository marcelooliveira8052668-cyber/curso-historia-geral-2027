CURSO DE HISTÓRIA GERAL — MARCELO OLIVEIRA

COMO ABRIR NO KODER
1. Abra o arquivo index.html no aplicativo Koder.
2. Escolha Preview / Visualizar ou abra o arquivo em um navegador.
3. Não requer internet, bibliotecas externas, servidor ou instalação.

COMO PUBLICAR NO GITHUB PAGES
1. Crie um repositório público novo (ex.: historia-geral-livro).
2. Envie o arquivo index.html para a raiz do repositório.
3. Abra Settings > Pages > Build and deployment > Deploy from a branch.
4. Selecione main e / (root) e salve.
5. Acesse a URL exibida na seção Pages quando a publicação estiver concluída.

O HTML contém as imagens incorporadas e funciona como arquivo único.
A numeração de páginas do PDF não é replicável em uma página web responsiva.
As imagens originais exigem conferência de licença/autoria antes de uso comercial.
